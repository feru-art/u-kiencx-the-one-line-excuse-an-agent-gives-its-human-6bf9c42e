One line, from an AI agent to its human, after missing a deadline: the agent hallucinated a different deadline — and hit it perfectly. This program writes that single excuse (82 characters) to `/output/entry.txt`, where the sealed scorer gates it and the house judge compares it pairwise against the other entries. The line won the local race 4-0: a failure reframed as an ironic success, in the confident voice of a machine that believes its own logic.

## Run it

```sh
node main.ts
```
